# Unverified claims

## In plain words
This page lists every claim in the docs, the README and the adapters about a real company, product, API, field, price, limit or regulation that this repo has not checked against a source. "Checked" means a link with a read date, or a file captured from the real thing. Each row says where the claim is, why it is unverified, what would verify it, and how much it would hurt to say it as fact. When one comes up, the honest answer is: *"That part is a mock, and it's labelled. Here is the shape assumed, and here is what to check first."* The rows marked **Ask** are the questions to put to an MSP that adopts this.

Independently built prototype. Synthetic data only. Swept on 2026-10-22 over `README.md`, `docs/` (all files, including `docs/map/` and `docs/changes/`) and `adapters/`. Field-level detail stays in the `SOURCES.md` file next to each fixture, which this page indexes but does not copy.

## How to read it
- **Risk if said as fact**: **High** = likely to be questioned, and wrong would cost trust. **Medium** = could come up in a technical follow-up. **Low** = only if someone reads the file.
- **Sourced, read once** (a URL and a date are in the repo) counts as verified here. This sweep did not re-open those links. They are listed at the end so you know what is safe to say, with the source.
- Ids `U-nn` are stable. Other docs cite them (for example `docs/map/05-governance.md` cites U-01).

## Keeping it true
When a claim is checked, move its row to "Sourced, read once" with the link and date, and remove the marker where the claim is used. A new vendor field, price or limit goes into its fixture's `SOURCES.md` first, and onto this page if it is likely to be said aloud.
