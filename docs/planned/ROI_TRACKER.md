# ROI tracker

Status: skeleton (filled in Phase 10). **All numbers will be fixture-based**: computed from this repo's synthetic data and stated assumptions, never from real clients or companies. They show the method, not real savings.

## Method
For each candidate automation: time per occurrence (assumed), occurrences per month (assumed), share handled without human edits (measured on fixtures), build effort, risk class (read-only, reversible write, irreversible write), and a priority score = (monthly hours saved x acceptance rate) / (effort x risk weight).
