# B-80 change note: gateway budgets, circuit breaker and model-call audit

Status: **built** (code, config, tests) against the mock and test-double providers. Counters are per process and in memory. Synthetic data only. Spec: `specs/B-80.md`.

## Why

A stuck loop or a provider outage must not run up cost or hide behind silence (roadmap `why`), and DR-17 says model calls are recorded nowhere.

## Individual to macro (L1-L4)

- L1: Ana, a technician, gets "budget exceeded" or "circuit open" at once instead of a hung ticket screen when a local model is down or an agent has used its share.
- L2: Contoso Dental's calls are charged to Contoso Dental's own budget, so a noisy Fabrikam Capital workload cannot starve it; each client's chain holds only its own model calls when an `AuditRouter` is used.
- L3: the MSP can show, per call, which agent used which provider and model, how big the request was and whether it was allowed, without any ticket text in the evidence. A runaway agent stops at its cap.
- L4: cost and availability controls for AI use that a small practice or firm can be told about in one sentence, with evidence that is safe to hand to an auditor.

## Honest limits

- Per-process counters: a restart or a second process starts from zero. Not a cross-process spend cap.
- Tokens are estimated from characters; no real tokenizer or provider usage is read. The limit numbers in `config/limits.json` are placeholders, not measured.
- Fixed windows (a burst across a boundary can reach twice the limit).
- Existing callers (triage, replies, summary, ...) pass no `agent`, so they share the `unattributed` agent budget (default 300 calls per hour). That is fine for today's workloads and fixtures; wiring real agent ids is a follow-up.
- Real providers are not exercised: the breaker's failure path is tested with doubles, and Ollama was not contacted.
- Gate note: `ruff format --check .` reports two files that were already unformatted on the base branch (`tests/py/tools/test_orphan_tests.py`, `workflows/enrichment/enrichment.py`). Neither is touched here; every file this item adds or edits is clean.

## DECISIONS proposal

D-0xx Gateway limits live in the gateway, fail fast, and are audited without content (B-80, 2026-10-27). Budgets (calls and estimated tokens per window) are kept per global, client and agent and enforced before any provider call, with all scopes charged atomically; a per-provider breaker opens after N consecutive failures and probes once after T seconds on an injected clock; every call writes a metadata-only `model.complete` record holding a SHA-256 of the redacted text that was sent, never the text, and a successful completion is withheld if its record cannot be written. Limits are in `config/limits.json`; a missing file means no limits so existing roots still load. Why: W-TOOL-02, W-TOOL-09; C-17, C-32, C-40, C-11; DR-17. Alternatives: a hash of the original text (rejected: a short PII value such as an SSN could be guessed from it offline); a background timer for the breaker (rejected: not deterministic to test). What would change it: a persisted shared ledger, real usage figures from providers, real prices.
