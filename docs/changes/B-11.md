## Honest limits

- **The notice step has no typed command on the page.** `docs/DEMO.md` (owned by `B-10`) does not yet include the `workflows.notify` command, and B11-2 allows only commands that are in DEMO.md. So the page names the folder and says the command arrives with the demo update. When B-10 lands, add the command line to the page's code block. The test will then confirm it is in DEMO.md.
- **The DEMO.md step 6 fallback** (`core.levers invoke ... --approved-by lead-lee`) is now refused without `--verified` (B-02). The page does not quote it, so the page is not affected. B-10 still has to fix that line.

- **The acronym and number checks are heuristics.** They handle capital-letter tokens and digits. They do not catch jargon written in lower case. Plain-language review is still a human job.
- **The page describes controls as working on fixtures.** `map/controls.json` still lists C-30, C-35 and C-36 as planned until the W1 fold applies the B-02/B-03/B-04 status changes. The page makes no status claims, so it stays true either way.
