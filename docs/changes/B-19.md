## DECISIONS proposal

D-0xx Per-family Graph state lives beside the client file (B-19, 2026-10-21). Family state is `fixtures/tenant/<client>/<family>.json`, must carry `_meta.client` equal to the folder's client, and is read only by that client's adapter; the adapter has no write method, and state changes only through the runner's diff-and-save path (SL-04). Why: parallel lever families without a shared edit hot-spot; C-04. Alternatives: one file with a section per family (merge conflicts); a shared folder keyed by client inside (a wrong path reads another client).
