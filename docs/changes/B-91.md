Status: **built** (shared suite, closed stubs, reference page). The stubs are stubs: every call fails closed. Synthetic data only. Spec: `specs/B-91.md`.

## What changed

- `tests/py/contract/test_b91_adapters.py` (new): one shared contract suite over the six adapter interfaces, each run for the mock and for the real stub (see the test count in the commit message and report).
- `adapters/real.py` (new, **outside `owns`**): `RealStub`, `RealPsa`, `RealRmm`, `RealIntune`, `RealGraph`, `RealBackup`, `RealAlerts` and the `REAL_STUBS` registry. No existing file was edited.

- `specs/B-91.md` (new), this note.

## Why

When the real PSA and RMM are known, plugging them in must be a checked step, not a leap: one registry, one suite, every implementation held to the same five rules (one client, no existence oracle, fail closed, no secret anywhere, deterministic errors).

## Individual to macro (L1-L4)

- L1: Ana, a technician, asks for a ticket that belongs to another client and gets the same "no such ticket for this client" she would get for a ticket that never existed.
- L2: Contoso Dental's adapter cannot be built from Fabrikam Capital's binding, and a stub refuses a pasted password where a secret name belongs.
- L3: the MSP gets a gate: a new vendor client enters `REAL_STUBS` and runs the whole suite before anything can select it.
- L4: fewer cross-client leaks and fewer secrets in logs when real integrations arrive, which is what SOC 2 CC6.1 and HIPAA 164.312(a) reviewers look for.

## Honest limits

- No real vendor API was called and no vendor page was opened. Field names, GDAP roles, SAM scopes and throttle figures in `docs/ADAPTERS.md` are from memory except the two sourced items it names; all are UNVERIFIED.
- Finding, not fixed (outside `owns`): `GraphMock` does not refuse another client's tenant GUID because the tenant fixtures carry no `_meta.tenantId`. One suite case is an imperative `xfail` for it.
- The suite proves mock behaviour and the closed stubs; it cannot prove a future real client until recorded vendor responses exist.
- Backup and alerts have no builder; the fixtures-poisoning check covers PSA, backup, alerts and RMM only.

## DECISIONS proposal

A stub refuses the `mock` implementation and any credential value, and answers every call `real adapter not configured`. Why: W-TOOL-11; C-02, C-27.
