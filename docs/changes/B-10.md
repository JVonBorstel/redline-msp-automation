## Honest limits

- The page is driven with the form fields the browser posts, not by clicking in a real browser.
- The smoke test does not run `scripts/clean.ps1` (it would delete the repo's `.tmp`) or the Phase 1 and Slice B suites. Each skipped line is listed with its reason, and the test checks that these lines are still in the doc.
- The 120-second budget is measured on the owner's laptop (about 25 s today). A slower machine, or the build automation's Low-integrity venv in TEMP, may take longer; the runner reports the time.
- `Test-Demo.ps1` is not yet in CI or the build automation's suite list. Adding it is a one-line change in files B-07 owns.
- The honesty and adaptation sections are pinned by sha256 (`test_b10_4_honesty_lines_and_week_one_plan_are_unchanged`). A deliberate edit updates the pin in the same PR. That is deliberate: the change gets seen.
- The page process is stopped with `taskkill /T` on Windows, because `uv run` starts python as a child process.
- The CLI path (`--verified callback-on-file` without a number source) is still looser than the page (B-03 limit). The demo fallback passes `--verified-ref number-on-file:psa-contact` so the record matches the page.
