# B-26: Drift fixes: single proposal definitions and TenantBaseline canonical ids

Status: built 2026-10-21. Inventory: W-TOOL-06, W-M365-11. Controls: C-06, C-21. Standards: STD-PR, STD-ID, STD-PS.

Three rows of the drift table in docs/map/03-architecture-target.md.

- DR-01 (STD-PR-5). `workflows/triage/proposal.py` no longer defines its own `proposal_id`, `Source` or UTC clock. It imports
  them from `core.queue.store`, and `make_proposal` builds the queue's `Proposal` model and returns it as the same dict
  shape as before (no `verification` key on a pending proposal). A triage proposal the queue would refuse (bad source,
  identity that is not a slug, naive time) now fails where it is made. `utc_now()` stays a datetime clock for triage and
  corrections, derived from the queue's helper.
- DR-05 (STD-ID-5). `TenantBaseline.config.json` keys tenants by the canonical client ids `contoso-dental` and
  `fabrikam-capital`, each with `fixtureDir` (the Graph fixture folder) and `aliases` (`contoso`, `clean`).
  `Get-TenantBaselineReport` / `Invoke-TenantBaseline` resolve `-Tenant` against the id or an alias, and the report's
  `tenant` field (findings.json, the CSV `Tenant` column, the result object) is always the canonical id.
- DR-10 (STD-LV-2). The config gains `plannedFixLevers`: `user.require-mfa`, `ca.block-legacy-auth`, `role.remove-member`.
  A test holds every named fix lever to "in levers/registry.json or planned", and drops a planned name the moment it is
  registered or no longer named.
- DR-09 (STD-PS-1). The manifest and the module's `#requires` declare PowerShell 7.4.

Acceptance (tests/py/levers/test_b26_fix_levers.py):

- B26-1 triage imports `proposal_id`, `Source` and the timestamp helper from core.queue; the proposal contract test is unchanged.
- B26-2 `-Tenant contoso-dental` works and `contoso` / `clean` stay aliases; the docs/DEMO.md command still works.
- B26-3 every fix lever is registered or planned; the manifest declares 7.4; SB-1 to SB-4 pass.

Out of scope: renaming `fixtures/graph/contoso` and `clean` (DR-22) and switching docs/DEMO.md and README.md to the
canonical id; the aliases keep both working until then.
