# B-37 Fact packs for human-only identity decisions

Status: **built** (fact pack module, CLI, two runbooks, tests). Read-only. Synthetic data only. Device field names are UNVERIFIED.

> Independently built prototype. Not affiliated with any vendor's or real company's systems. Synthetic data only.

Inventory: `W-ONB-15` (urgent or hostile termination), `W-IDM-04` (caller identity verification), `W-IDM-06` (Conditional Access policy change), `W-IDM-07` (privileged role grants). All four are "none-keep-human" and R3. Controls: `C-20` (read levers cannot write), `C-27` (one client per unit of work), `C-42` (staff know what an approval means). Depends on `B-19` (Graph mock adapter). Standards: `STD-DC`, `STD-ID`, `STD-TS`. Decisions in force: `D6-05` (R3 needs two signed-in human leads), `D6-06` (callback on the number on file), `D6-07` (identity changes are R3).

## Why

Humans decide the hardest cases faster with the facts in front of them, and no bot in the loop. The fact pack is a page of facts for the human who decides; it is not a recommendation.

## Behaviour

- **CLI** `python -m workflows.factpack <kind> --client <id> --target <id>`. Kinds: `termination` (W-ONB-15), `caller` (W-IDM-04), `role` (W-IDM-07), each for one person (user principal name or id), and `policy` (W-IDM-06) for one Conditional Access policy (id or display name). Prints JSON. Exit 0 = ran, 2 = bad input or target not in this client's data.
- **Person pack**: account, authentication (method types only; no phone numbers or other contact details), sessions (the mock's session count, which is INVENTED, and the last five sign-ins), devices, directory roles, groups (privileged flagged), Conditional Access policies (includes all users, includes or excludes this user, has group or role scope), `holdsPrivilegedAccess`, and `gaps` for every section whose source has nothing on the person.
- **Policy pack**: state and report-only flag, conditions, grant controls, the excluded users (with whether each holds a directory role), scope counts, the other policies. Group and role membership of include lists is not resolved and is listed as a gap.
- **Always** `readOnly: true`, `leversRegistered: []`, `proposals: []`, and a `decision` line pointing to the runbook. The module opens files for reading only and imports no lever runner, queue or approval code.
- **Isolation** (`C-27`, STD-ID-4): client is explicit; the tenant store is opened through `GraphMock` for that client only; the baseline folder and the device slice are chosen by that client's id. A person of another client and an absent person get the same error words.
- **Untrusted text** (`C-12`): names and failure texts the injection detector flags are replaced by a fixed sentence and listed under `withheld`.
- **Sources**: `fixtures/tenant` through `GraphMock` (users, sessions, sign-ins, groups); `fixtures/graph/<contoso|clean>` (users, registration, directory roles, Conditional Access; verified-or-not status in `fixtures/graph/SOURCES.md`); `workflows/factpack/fixtures/devices.json` (new, synthetic stand-in, every field UNVERIFIED). The two people sets overlap only partly, so a person is looked up in both and the pack says which sources had them.
- **Runbooks** `docs/runbooks/urgent-termination.md` and `docs/runbooks/caller-verification.md` (procedure for humans; the MSP's real procedure is UNKNOWN).

## Acceptance

- **B37-1** `python -m workflows.factpack <kind> --client <id> --target <id>` assembles read-only facts (accounts, sessions, devices, roles, Conditional Access policies) for one person or one policy, registers no lever and proposes nothing. Also: no fixture or audit file changes; another client's data never appears; bad input is refused; gaps are stated, flagged text is withheld.
- **B37-2** The urgent-termination runbook keeps timing and conduct with named humans (roles recorded in the ticket, not in the file); the caller-verification runbook describes the callback-on-file method the approval page records (the three number-on-file sources, the `number-on-file:<source>` label, never the number).
- **B37-3** A test asserts the fact pack module imports no runner execute path (an AST check of every file in the package, plus a namespace check and a no-write check).

Tests: `tests/py/factpack/test_b37_factpack.py`, every test named `test_b37_<k>_...` (run: `uv run --frozen pytest -p no:cacheprovider tests/py/factpack`).
