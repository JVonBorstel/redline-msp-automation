# B-19 Graph mock adapter with per-family state

Status: **mocked** (Graph mock, builder and tests exist; no real Graph implementation). Synthetic data only.

> Independently built prototype. Not affiliated with any vendor's or real company's systems.

Inventory: `W-TOOL-11`. Controls: `C-04` (client isolation), `C-05`, `C-27`. Standards: `STD-FX`, `STD-ID`, `STD-LV`. Depends on `B-18` (adapter base, bindings). Architecture: `SL-04`, `ARC-05`.

## Why

Each identity lever family (devices, licenses, groups, mailboxes) needs its own mock state. Editing one shared `fixtures/tenant/<client>.json` from every family means merge conflicts and one family breaking another. A family brings `fixtures/tenant/<client>/<family>.json` instead, and the adapter serves both, always for one client.

## Behaviour

- `adapters/graph/base.py`: vendor-neutral `GraphAdapter` (system `m365`): `state`, `families`, `family_state`, `list_users`, `get_user`, `list_authentication_methods`. No write method exists.
- `adapters/graph/mock.py`: `GraphMock(client, binding, root)`. Built from the client's `m365` binding; the base file and every family file must name the client in `_meta.client`; an optional `_meta.tenantId` must equal the binding's external id. The client id becomes a path only through `MockTenant.path_for`; family names are slugs.
- `adapters/graph/__init__.py`: `build_graph_adapter(client)` reads `config/clients/<client>.json`; any implementation other than `mock` returns `real adapter not configured`.
- Each call re-reads disk and returns deep copies. A lookup of another client's user answers like an absent one.

## Acceptance

- **B19-1** the Graph mock reads the existing fixtures/tenant/<client>.json plus optional fixtures/tenant/<client>/<family>.json files; a family file for another client is never read
- **B19-2** state reads return copies; writes go only through the runner's diff-and-save path (SL-04)
- **B19-3** SOURCES.md lists each new Graph shape with its Microsoft Learn page and Verified/UNVERIFIED per field (STD-FX-2)

Tests: `tests/py/adapters/test_b19_graph.py`, named `test_b19_<k>_...`.
