# B-50: TenantBaseline drift over time: Conditional Access and findings

Status: built 2026-10-22. Inventory: W-IDM-06, W-M365-11. Controls: C-21, C-20. Standards: STD-PS, STD-TS.

`-CompareTo <previous findings.json>` on `Get-TenantBaselineReport` and `Invoke-TenantBaseline` (`levers/powershell/TenantBaseline`).
Why: a silently weakened policy is noticed the next morning, not months later.

- Snapshot. Every report now carries a top-level `conditionalAccess` array (id, displayName, state, and an `assignments`
  block: include/exclude users, groups, roles and applications), sorted by id with every list sorted, so a `findings.json` can be
  the next run's "previous" file. `TenantBaselineFinding`, `counts`, `settings` and `metrics` are unchanged.
- Drift. Only with `-CompareTo`, a top-level `drift` key:
  - Findings are matched on `CheckId` plus `Subject`, not on `Id` (the numbered suffix moves when findings come and go). `new` is
    in this run only, `resolved` in the previous run only, `unchanged` in both. A change in evidence text alone is unchanged.
  - CA policies are matched on `id`: `added`, `removed`, `stateChanged` (from, to) and `assignmentsChanged` (per field, added and
    removed values). Order alone never counts as a change.
  - A previous file with no `conditionalAccess` key (older version) skips the CA diff with an explicit note.
  - A missing file, malformed JSON, a file without a `findings` array, or a file for another tenant throws.
- Outputs (compare mode only): the `drift` key in `findings.json`, a "Changes since previous run" section in `report.html`
  (HTML-encoded, no script, src or href), and a new `drift.txt`. Without `-CompareTo` the four files are as before.
- Report only (never-automate). Drift entries have no `FixLever`, `FixMode` or `FixTarget`; the drift code never reads
  `fixLevers`; nothing is added to the config. The drift text says Conditional Access changes are a human decision.

Acceptance (tests/sliceb/Test-SliceB.ps1, names start with the id):

- B50-1 new, resolved, unchanged findings and CA state or assignment changes (plus added and removed policies, no false positives, errors, outputs).
- B50-2 drift is a report only: no lever, no fix mode, config untouched.
- B50-3 SB-1 and SB-2 still pass; a default run has no drift key and writes the same four files; the demo command is unchanged.
