# B-06 Map integrity test and the Python suite runner

Status: **built** (mocked data only; synthetic planning maps)

## Acceptance

- **B06-1** Every id in `map/inventory.json`, `map/controls.json` and `map/roadmap.json` is unique and matches its pattern (`W-<AREA>-<nn>`, `C-<nn>`, `B-<nn>`, `W<n>`).
- **B06-2** Every inventory id and control id named in `roadmap.json` resolves; every `depends_on` resolves to an item in the same or an earlier wave, and the graph has no cycle.
- **B06-3** Every inventory id is covered by at least one roadmap item or by a `not_now` entry.
- **B06-4** No two items in one wave own the same path, and no owned directory contains a path owned by another item in that wave.
- **B06-5** `tests/py/Test-Py.ps1` prints exactly one `Py tests: N passed, M failed` line and exits non-zero on any failure (STD-TS-5). A missing `uv` is a failure (skipped, never passed). An empty `tests/py` counts as zero tests.
- **B06-6** An inventory `risk_class` that differs from the governance class prints a `WARNING:` line naming the id; it never changes the exit code (open question RQ-01).

## Tests

`tests/phase1/test_map.py` (checks and warnings), `tests/py/Test-Py.ps1` (the runner).
