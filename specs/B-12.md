# B-12 Repo paths, gateway and guard drift, config version field

Status: **built** (`core/paths.py`, `core/gateway/config.py`, the `__future__` import across `core/gateway` and `core/guard`; checked by `tests/py/core/test_b12_paths.py`).

> Independently built prototype. Not affiliated with any vendor's or real company's systems. Synthetic data only.

Inventory: `W-TOOL-02`. Controls: `C-16`, `C-15`. Depends on nothing. Drift rows: `DR-07`, `DR-08`, `DR-14` (`docs/map/03-architecture-target.md`). Standards: `STD-PY-6`, `STD-PY-8`, `STD-CF-4`, `STD-CF-9`.

## Why

Removes working-directory surprises before many new modules depend on them. Before this item the gateway config loader read `config/models.json` and `config/routing.json` relative to the current directory, and `python -m core.gateway` defaulted `--root` to `.`, so the same command gave a different result (or a file-not-found) depending on where it was typed.

## Behaviour

- `core/paths.py` defines one `REPO_ROOT` (an absolute path found from the module's own location). It is the single helper STD-PY-8 asks for; other modules adopt it when next touched.
- `GatewayConfig.load(root=REPO_ROOT)` and `GatewayConfig.root` default to `REPO_ROOT`. `python -m core.gateway --root` defaults to `REPO_ROOT`. An explicit root still wins (tests and copies under `tmp_path`).
- Every module in `core/gateway/` and `core/guard/` starts (after its docstring) with `from __future__ import annotations`. No behaviour change.
- `GatewayConfig.version` is `Literal[1] | None`. `load` reads `version` from each file: absent is accepted (for now), the integer `1` is accepted, anything else (`0`, `2`, `"1"`, `true`, `1.0`, `null`, a list) raises `ValueError` naming the file. Look-alikes are refused even on direct `model_validate`.

## Acceptance

- **B12-1** `core.paths.REPO_ROOT` is the default root for the gateway config loader (DR-08); running from another working directory (in-process `chdir` and the CLI as a subprocess from `tmp_path`) loads the same files and gives the same mock completion.
- **B12-2** every gateway and guard module has `from __future__ import annotations` as its first statement after the docstring (DR-14), with no behaviour change; `tests/phase1/test_guard.py` (P1-7) and `tests/phase1/test_gateway.py` (P1-8) still pass, run from inside the B-12 test.
- **B12-3** `GatewayConfig` accepts `version: 1`, rejects any other value, and accepts an absent version only until the owner wiring adds it to both committed files (DR-07, tracked). A bad version in one file is refused even when the other file is good.

Tests: `tests/py/core/test_b12_paths.py` (46 cases). Run with `uv run --frozen pytest -p no:cacheprovider tests/py/core`.
