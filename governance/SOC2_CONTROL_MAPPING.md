# SOC 2 control mapping

Status: **document-only** (generated claims with backing; the tests it cites are built, the mapping is not an audit)

> Independently built prototype. Not affiliated with any vendor's or real company's systems. Synthetic data only.

This page is generated by `uv run --frozen python -m workflows.assurance generate --write` from `map/controls.json`, `governance/soc2_mapping.json` and the repo. Do not edit it by hand; `check` fails when it drifts or when a cited test or file does not exist.

**This is not a certification, not an attestation and not an audit result.** Each row is a claim this system makes about one control, with the tests and files that back it on synthetic fixtures, and an explicit list of what is not demonstrated. No auditor has seen it. Whether the MSP holds any SOC report is UNVERIFIED (docs/UNVERIFIED.md U-01).

## How to read it

- Status is `built`, `partial` or `planned` exactly as `map/controls.json` derives it. A control built after the map was last updated still reads as the map says (see RR-4 in `governance/RISK_REGISTER.md`); that understates, never overstates.
- Criterion ids are copied from the `SOC2:` entries of `framework_refs` in the map. The AICPA criteria text is not in this repo and was not consulted, so whether each id fits its control is the map author's judgement (UNVERIFIED).
- A test is cited as `path::name`. The checker confirms the file exists and defines that test; it does not run the test. The test suite does that, on fixtures, with mock providers and no real tenant.
- A SOC 2 Type II report concerns operation over a period. Nothing here covers a period, a population, a sample or a real client: **operating effectiveness is not demonstrated for any control.**
